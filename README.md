# wordle
Unlimited Wordle + Engine

## Motivation
The motivation for this project is to allow for infinite Wordles to be played, without the use of a third-party site or to wait for the daily countdown from the New York Times. In addition, this project also seeks to utilize various information theory/probability theory concepts used by the current WordleBot and implement them in this new version of Wordle.
